Scenarios are in `scripts/e2e/pi/pi-idle-compression.e2e.ts`, all co-installed with `pi-autocompact`. Regressions were applied to `pi-idle-compression/index.ts` and restored.

## Findings

- **The guards do less on the plain path than the design says.** With both removed, the plain co-installed path sends no second summary: Pi's `compact` refuses with `Already compacted` because a compaction is the last entry (`agent-session.js:2266`, `prepareCompaction`). There the guards prevent a user-visible warning, so `I1 silent` asserts on notices. Its first form asserted only the summary count and passed with both guards removed, so it was corrected.
- **A paid second summary is reachable only with an entry after the compaction.** `I1 unmeasured` uses a fixture that leaves a large `custom_message` at `agent_before_settle`, right after the boundary compaction. The last entry is then not a compaction, Pi does not refuse, and only the `tokens === null` guard stops a second paid summary (observed: 2 summaries without it).
- **Not detected: the last-entry guard removed alone** (`I1 silent` and `I1 unmeasured` both pass). This looks like an equivalent mutation: `getContextUsage` returns `tokens: null` whenever no assistant reply follows the latest compaction, which holds when a compaction is the last entry, so the `tokens === null` guard covers it. That reasoning is from reading the host; the passing run is what was observed.
- **Not detected: the `tokens === null` guard removed alone, on `I1 silent`** (the last-entry guard covers it). `I1 unmeasured` does detect it.
- **Not detected: `timer.unref()` removed alone, or the `session_shutdown` handler removed alone** (`I2` passes each way). Either one is enough for print mode to exit promptly: Pi's shutdown cancels the timer, and an unref'ed timer does not hold the process. Removing both hangs. The package's `unref` is thus a second line of defence in print mode, not the only one, contrary to the audit's inferred contract row.
- No published file of this package changed, so there is no release decision.
- No audit deviation. Result: 7 DELETE, 1 to E2E (`arms a resumed conversation` to `I1 reopen`), 25 stay; vitest reports 25 cases.
